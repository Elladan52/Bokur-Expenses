Google Sheets Integration Setup

Sync expenses instantly into your personal sheet

⚡ Method 1: Free Google Apps Script Webhook (Recommended)

Requires a 1-minute setup. The web app sends HTTP POST directly into your Google Sheet without OAuth authorization headaches!

How to get your Webhook URL in 60 seconds:

  1. Open your Google Sheet at sheets.new.
  2. Click Extensions > Apps Script.
  3. Delete existing code and paste this snippet:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([data.amount, data.description, data.category, data.date]);
  return ContentService.createTextOutput(JSON.stringify({'result': 'success'}))
    .setMimeType(ContentService.MimeType.JSON);
}
  1. Click Deploy > New Deployment.
  2. Select type: Web App. Set "Who has access" to Anyone.
  3. Click Deploy and paste the resulting Web App URL above!
